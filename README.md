# About Me

Hi, I'm Jakub Pondo (`sieciowiec.xyz`).

I build secure Linux platforms, backend systems, and cloud-native infrastructure with a focus on reliability, reproducibility, and security.

My background is in Linux platform architecture, systems security, infrastructure automation, and image-based delivery for high-trust and air-gapped environments. I work mainly with Python, Shell, and Rust, and I'm especially interested in the overlap between platform engineering, cloud, Kubernetes, and AI systems.
